# ImGui DirectX12 Hook (Visual Studio .sln Version)

This project is a Visual Studio `.sln`-based version converted from the original CMake setup.  
It uses **ImGui**, **DirectX 12**, and **Kiero Hook** to inject a custom GUI overlay into DirectX 12 applications.

## Features

- ImGui-based UI rendering
- Hooking with Kiero for DirectX 12
- Converted to Visual Studio `.sln` format
- Ready for further development and debugging

## How to Build

1. Open the `.sln` file with Visual Studio 2022 (or newer).
2. Make sure the Platform Toolset and Windows SDK version match your system.
3. Build the solution using `Ctrl + Shift + B` or from the Build menu.
